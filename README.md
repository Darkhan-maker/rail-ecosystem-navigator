# Rail Ecosystem Navigator

Презентационный сайт цифровой экосистемы для железнодорожной отрасли:
карта продуктов, ролей и сценариев — от рабочего места механика
до аналитики для руководителей.

Автор: Дархан Макажанов, старший электромеханик СЦБ и связи,
основатель ТОО «Ortaq Hub» (ortaqhub.kz).

Связанные проекты:
- Ortaq Hub — платформа цифрового наряда-допуска и контроля
  готовности персонала (закрытый репозиторий, свидетельство № 72577)
- RailHub — цифровое рабочее место механика

## Стек

Next.js, React, TypeScript, Tailwind CSS. Деплой — Vercel.

## Запуск

pnpm install
pnpm dev

Открыть http://localhost:3000
